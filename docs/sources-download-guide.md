# Sources目录下载功能使用指南

## 功能概述

Sources目录下载功能允许您浏览和下载页面的资源文件，保持目录结构，并打包成zip文件。

## 核心特性

### 1. 目录树展示
- **三级目录限制**：最多展示三级目录结构，避免过深的嵌套
- **智能分组**：按域名自动分组资源文件
- **文件图标**：根据文件类型显示不同图标（JS、CSS、HTML等）

### 2. 交互功能
- **展开/折叠**：点击目录名或箭头图标展开/折叠
- **批量选择**：支持选择单个文件或整个目录
- **全部展开**：一键展开或折叠所有目录
- **搜索过滤**：支持按文件名或路径搜索

### 3. 下载功能
- **并发下载**：最多5个文件同时下载，提升速度
- **进度显示**：实时显示下载和打包进度
- **保持结构**：下载时保持原有目录结构
- **自动打包**：下载完成后自动打包成zip文件

## 使用步骤

### 步骤1：扫描资源
1. 打开侧边栏
2. 切换到"Sources下载"标签
3. 点击"扫描资源目录"按钮
4. 等待扫描完成

### 步骤2：选择文件
1. 浏览目录树结构
2. 点击目录前的箭头展开子目录
3. 勾选要下载的文件或目录
4. 可以使用"全部展开"按钮快速查看所有文件

### 步骤3：下载打包
1. 点击"下载并打包"按钮
2. 观察下载进度
3. 等待打包完成
4. zip文件会自动下载到本地

## 技术实现

### Chrome Debugger API
本功能使用Chrome Debugger API访问页面资源：
- `chrome.debugger.attach` - 附加到标签页
- `Page.getResourceTree` - 获取资源树
- `Page.getResourceContent` - 获取文件内容
- `chrome.debugger.detach` - 分离调试器

### 权限要求
需要在manifest.json中声明`debugger`权限：
```json
{
  "permissions": ["debugger"]
}
```

### 限制和注意事项

1. **调试器限制**
   - 同一时间只能有一个调试器附加到标签页
   - 使用时DevTools不能同时打开
   - 附加时页面会显示调试提示

2. **性能考虑**
   - 大文件下载可能较慢（30秒超时）
   - 并发限制为5个文件
   - 建议分批下载大量文件

3. **CORS限制**
   - 某些跨域资源可能无法下载
   - 使用`credentials: 'omit'`避免CORS问题
   - 失败的文件会被跳过，不影响其他文件

## 目录树结构

### 示例
```
example.com/
├── js/
│   ├── app.js
│   ├── vendor.js
│   └── utils/
│       └── helper.js
├── css/
│   ├── main.css
│   └── theme.css
└── index.html
```

### 深度限制
- **一级**：域名（如example.com）
- **二级**：目录（如js、css）
- **三级**：子目录或文件

超过三级的目录会被截断，确保界面简洁。

### 脚本文件

- 图片文件（可选）

## 最佳实践

### 1. 选择性下载
- 只选择需要的目录和文件
- 避免下载过大的文件
- 注意文件数量限制

### 2. 分批处理
- 大型网站建议分批下载
- 每批不超过50个文件
- 避免一次性下载过多

### 3. 错误处理
- 查看错误提示
- 重试失败的文件
- 检查网络连接

## 故障排除

### 问题1：扫描失败
**可能原因**：
- 页面未完全加载
- 权限不足
- DevTools已打开

**解决方案**：
- 等待页面加载完成
- 检查扩展权限
- 关闭DevTools后重试

### 问题2：下载失败
**可能原因**：
- CORS限制
- 网络超时
- 文件不存在

**解决方案**：
- 检查控制台错误信息
- 重试下载
- 手动下载失败的文件

### 问题3：打包失败
**可能原因**：
- 内存不足
- 文件过大
- 浏览器限制

**解决方案**：
- 减少文件数量
- 分批下载
- 重启浏览器
