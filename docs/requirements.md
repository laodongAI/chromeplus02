# 需求规格说明书 (Requirements Specification)

## 1. 引言
本项目是一个基于 Chrome Manifest V3 的网页内容分析与媒体抓取扩展。旨在为用户提供便捷的视频下载、音频录制、画面截图以及 AI 辅助分析功能。

## 2. 功能模块需求 (Functional Requirements by Module)

本系统采用 Tab 页签式导航，每个 Tab 对应一个独立的功能模块。

### 2.1 视频采集模块 (Video Capture Module)
**对应 Tab**: `视频采集`
**目标**: 识别并控制页面视频，支持录制与抓帧。

| 功能点 | 输入/控件 | 逻辑描述 |
| :--- | :--- | :--- |
| **重新扫描** | 按钮 `重新扫描` | 触发 `refreshVideoList`，向 Content Script 发送 `GET_VIDEO_LIST` 消息，重新获取当前页面的视频列表。 |
| **连接重试** | 按钮 `重试连接` | 触发 `ensureConnectAndRefresh`，尝试重新注入 Content Script 并建立连接，解决连接丢失问题。 |
| **Frame 选择** | 下拉框 `frame-select` | 选择扫描范围：`自动选择` (默认)、`顶层窗口` 或特定的 `iframe`。改变后自动刷新列表。 |
| **批量录制** | 按钮 `批量录制` | 触发 `startRecordAll`，对列表中所有视频发送 `START_RECORD_VIDEO` 指令。 |
| **停止所有录制** | 按钮 `停止所有录制` | 触发 `stopRecordAll`，对所有正在录制的视频发送 `STOP_RECORD_VIDEO` 指令。 |
| **下载选中** | 按钮 `下载选中` | 触发 `downloadSelected`，将勾选的视频加入下载队列。 |
| **状态过滤** | 下拉框 `filter-select` | 筛选列表显示：`全部状态`、`未下载`、`已下载`。 |
| **全局播放控制** | 按钮 `▶` / `⏸` | 触发 `togglePlayAll`，控制页面上所有视频的播放或暂停。 |
| **单体播放控制** | 列表按钮 `播放`/`暂停` | 控制单个视频元素的播放状态。 |
| **单体录制控制** | 列表按钮 `录制`/`停止` | 控制单个视频的录制。录制开始时显示计时器，停止时自动下载 WebM 文件。 |
| **单体下载** | 列表按钮 `下载` | 直接下载该视频资源的原始 URL（如果可访问）。 |
| **搜索** | 输入框 `搜索视频` | 本地过滤视频列表，支持快捷键 `Ctrl+F` 聚焦。 |

### 2.2 图像抓取模块 (Image Grab Module)
**对应 Tab**: `图像抓取`
**目标**: 扫描页面图片，支持预览、复制与批量下载，以及视频帧捕获。

| 功能点 | 输入/控件 | 逻辑描述 |
| :--- | :--- | :--- |
| **抓帧间隔设置** | 输入框 `间隔(秒)` | 设置自动抓取视频帧的时间间隔，默认为 5 秒。 |
| **抓帧开关** | 按钮 `开始抓帧`/`停止抓帧` | 开启/关闭定时器。开启后，每隔指定秒数截取当前播放视频的画面并添加到列表。 |
| **重新扫描** | 按钮 `重新扫描` | 向 Content Script 发送 `REQUEST_IMAGE_LIST`，获取页面 `<img>` 标签及背景图。 |
| **全选/反选** | 按钮 `全选`/`取消全选` | 批量选择/取消选择列表中的所有图片。 |
| **清空列表** | 按钮 `清空` | 清空当前列表中的所有图片记录。 |
| **批量下载** | 按钮 `批量下载` | 将选中的图片加入下载队列。 |
| **尺寸过滤** | 输入框 `最小宽度`/`最小高度` | 过滤掉尺寸小于指定值的图片（如 Icon、小图标）。 |
| **状态过滤** | 下拉框 `filter-select` | 筛选 `全部`、`未下载`、`已下载`。 |
| **图片预览** | 列表缩略图 | 使用 `IntersectionObserver` 懒加载图片预览。 |
| **复制链接** | 列表按钮 `复制` | 将图片 URL 复制到剪贴板。 |
| **单体下载** | 列表按钮 `下载` | 将单张图片加入下载队列。 |

### 2.3 音频抓取模块 (Audio Grab Module)
**对应 Tab**: `音频抓取`
**目标**: 提取音频资源，进行单个或批量下载，支持从视频提取音频。

| 功能点 | 输入/控件 | 逻辑描述 |
| :--- | :--- | :--- |
| **重新扫描** | 按钮 `重新扫描` | 向 Content Script 发送 `REQUEST_AUDIO_LIST`，获取 `<audio>` 标签及相关资源。 |
| **音频内录** | 按钮 `提取当前播放视频音频` | 触发 `toggleAudioRecording`。开始录制当前 Tab 的音频流（Tab Capture），再次点击停止并下载。 |
| **批量下载** | 按钮 `下载所选` | 将勾选的音频资源加入下载队列。 |
| **状态过滤** | 下拉框 `filter-select` | 筛选 `全部`、`未下载`、`已下载`。 |
| **搜索** | 输入框 `搜索音频` | 本地过滤音频列表（标题/URL）。 |
| **单体下载** | 列表按钮 `下载` | 将单个音频加入下载队列。 |
| **复制链接** | 列表按钮 `复制链接` | 复制音频 URL。 |

### 2.4 文本抽取模块 (Text Extraction Module)
**对应 Tab**: `文本抽取`
**目标**: 提取页面正文、元数据与结构化信息。

| 功能点 | 输入/控件 | 逻辑描述 |
| :--- | :--- | :--- |
| **提取文本** | 按钮 `提取文本` | 向 Content Script 发送 `GET_TEXT_CONTENT`，获取标题、作者、描述、关键词及正文内容。 |
| **复制 JSON** | 按钮 `复制 JSON` | 将提取到的所有结构化数据以 JSON 格式复制到剪贴板。 |
| **复制正文** | 按钮 `复制正文` | 仅复制提取到的正文文本。 |
| **元数据展示** | 标签/文本 | 展示页面的 Title, Author, Description, Keywords。 |
| **正文预览** | 文本区域 | 展示提取到的正文前 5000 字预览。 |

### 2.5 下载任务模块 (Download Manager Module)
**对应 Tab**: `下载任务`
**目标**: 查看下载历史与任务状态。

| 功能点 | 输入/控件 | 逻辑描述 |
| :--- | :--- | :--- |
| **状态过滤** | 下拉框 `filter-select` | 筛选 `全部`、`下载成功`、`下载失败`。 |
| **类型过滤** | 下拉框 `filter-type` | 筛选 `全部`、`视频`、`图片`、`音频`。 |
| **刷新列表** | 按钮 `刷新` | 从 `chrome.storage` 重新加载下载历史记录。 |
| **清空历史** | 按钮 `清空历史` | 清除所有下载记录（不删除文件）。 |
| **任务重试** | 列表按钮 `重试` | 对失败的任务重新加入下载队列。 |
| **复制链接** | 列表按钮 `复制链接` | 复制原始资源链接。 |

### 2.6 系统设置模块 (Settings Module)
**对应 Tab**: `系统设置`
**目标**: 配置扫描策略、命名模板与存储路径。

| 功能点 | 输入/控件 | 逻辑描述 |
| :--- | :--- | :--- |
| **自动扫描** | 复选框 `自动扫描` | 开启后，页面加载完成时自动触发资源扫描。 |
| **快捷键提示** | 复选框 `显示快捷键提示` | 控制搜索栏下方的快捷键提示文本显示。 |
| **命名模板** | 输入框 `命名模板` | 定义下载文件的命名规则。支持变量 `{site}`, `{title}`, `{date}`, `{time}`, `{index}`。 |
| **并发上限** | 输入框 `并发上限` | 设置同时进行的最大下载任务数 (1-10)。 |
| **清除历史** | 按钮 `清除下载历史` | 快捷清除所有下载历史记录。 |
| **自动保存** | (无显式按钮) | 修改表单后，防抖 (400ms) 自动保存设置到 `chrome.storage`。 |

## 3. 非功能需求 (Non-Functional Requirements)

| 需求ID | 类别 | 描述 |
| :--- | :--- | :--- |
| **NFR-01** | **响应性** | 侧边栏切换 Tab 无明显延迟。 |
| **NFR-02** | **持久化** | 用户设置、下载历史需持久化存储，重启浏览器不丢失。 |
| **NFR-03** | **鲁棒性** | 页面刷新或关闭后，扩展应能自动重连或优雅处理连接断开错误。 |
