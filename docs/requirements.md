# 产品需求说明（业务流程）

本文档定义本插件的产品目标、业务流程、功能需求与非功能要求，作为开发与测试的统一依据。

## 1. 产品目标
- 识别网页中的三类媒体资源：视频、音频、图片。
- 提供对视频的播放/暂停控制、视频录制（含仅音轨录制）、视频帧抓取与保存。
- 提供对音频与图片的列表化展示、单个/批量下载与复制链接。
- 以侧边栏（Side Panel）为主界面，支持批量操作、进度提示与失败重试。

## 2. 业务流程（端到端）
1) 进入目标网页并打开侧边栏。
2) 触发资源扫描（自动或手动）：
   - 扫描 `<video>`/`<audio>`/`<img>`/`<source>`/`<picture>`、`meta og:*`、以及可选的 `<link rel="preload">`、`JSON-LD` 中媒体线索。
3) 在侧边栏展示“视频/音频/图片”三类清单（数量徽标）：
   - 支持复选与批量操作；支持单项操作（播放/暂停、录制、抓帧、复制、下载）。
4) 执行用户选中的操作：
   - 视频：播放/暂停、录制（视频+音频或仅音频）、抓帧导出为 PNG、尝试直链下载（如可得）。
   - 音频：复制直链、下载单个/批量。
   - 图片：预览、复制直链、下载单个/批量。
5) 通过 `chrome.downloads` 下载；在通知区显示进度与结果，失败可重试。

## 3. 功能需求（编号）
- R-VID-DET-001：识别页面内所有 `<video>` 元素，并采集分辨率、时长、是否静音、来源链接。
- R-AUD-DET-001：识别页面内音频资源（`<audio>`/`<source>`/`<a>`直链/`og:audio`）。
- R-IMG-DET-001：识别图片资源（`<img>`/`<picture>`/`<source>`/`og:image`/常见 CSS 背景）。
- R-VID-CTRL-001：对选中视频执行播放/暂停（逐条控制）。
- R-VID-REC-001：录制选中视频（包含视频与音频），保存为 WebM；支持仅音轨录制保存为 WebM/Ogg。
- R-VID-FRAME-001：抓取选中视频当前帧，导出为 PNG。
- R-VID-REC-002：在侧边栏针对单条视频提供“开始录制/停止录制”控制，录制结束后自动调用 `chrome.downloads` 以 `{siteName}_{title}_{timestamp}_record.webm` 命名保存，侧边栏需展示录制中状态与耗时；录制失败（DRM、无 captureStream）时给出明确提示并提供降级方案（如截图）。
- R-VID-DL-001：在识别到的视频列表中显示可用的源文件直链（`video.src`、`<source>`、播放器暴露的下载地址）；提供“下载原视频”按钮，通过 `chrome.downloads` 直接保存，支持命名模板、进度与失败重试；无法获取直链时需提示用户改用录制方案。
- R-VID-AUD-001：在单条视频上提供“提取音频”操作，仅录制音轨并导出 WebM/Ogg 格式音频，命名为 `{siteName}_{title}_{timestamp}_audio.ext`；录制期间需显示状态并允许取消，完成后自动下载；若页面禁用了音轨捕获需提示。
- R-DL-LIST-001：对音频/图片提供列表操作：单个/批量下载与复制链接。
- R-DL-PROG-001：展示下载进度与状态变化，支持失败重试与取消。
- R-UI-BATCH-001：支持全选/反选、筛选（类型/域名/大小阈值），并发下载上限可配置。
- R-SET-NAME-001：文件命名模板（如：`{siteName}_{title}_{date}_{index}`），非法字符清理。
- R-SET-AUTO-001：自动扫描开关、默认录制封装/质量、下载并发上限配置（`chrome.storage.local` 持久化）。
- R-ERR-HINT-001：对 DRM/CORS/用户手势受限等情况提供清晰提示与替代方案。

## 4. 非功能需求
- 权限最小化：仅使用 `tabs/scripting/storage/sidePanel/downloads` 及必要 `host_permissions`。
- 性能：普通页面扫描 < 100ms；大图列表采用懒加载/分页。
- 兼容：MV3 架构；对不支持 `captureStream()` 的页面，提供降级策略（可视区域截图/直链下载）。
- 可维护：需求-设计-代码映射清晰，任务跟踪文档保持更新。

## 5. 约束与已知限制
- DRM/EME 页面可能禁止录制与抓帧；跨域画布会被 taint 无法导出；下载可能需用户登录 Cookie。
- 录制/下载通常需要用户手势触发，避免被浏览器拦截。

## 6. 验收标准（示例）
- 能在 B 站/YouTube/知乎等页面正确识别三类资源并展示列表。
- 可对列表中选定的视频播放/暂停、录制并成功保存文件、抓帧导出为 PNG。
- 音频/图片可单个/批量下载，列表有数量与进度提示。
- 设置项持久化生效，命名模板应用于所有导出文件。
