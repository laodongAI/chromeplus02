# 测试策略与用例

## 1. 测试范围
- 单元：工具与解析（未来迁移 TS 后用 Vitest）。
- 集成：内容脚本扫描、注入执行、消息交互、下载触发。
- 手动/E2E：常见站点页面的识别/控制/录制/抓帧/下载闭环。

## 2. 场景用例（示例）
- B站视频页
  - 扫描视频=1+；播放/暂停指定索引有效；录制 10s 成功保存；抓帧成功保存。
- YouTube 视频页
  - 扫描视频、音频直链（如可得）；音频单个/批量下载成功。
- 图文页面（知乎）
  - 扫描图片=10+；预览、复制、批量下载成功；命名符合模板。

## 3. 失败与回退用例
- DRM 页：录制/抓帧失败，展示明确提示并建议使用页面截图/直链下载。
- 跨域图片：画布导出失败，提示并使用 `captureVisibleTab` 方案。
- 下载失败：展示错误并提供重试；批量下载中断可恢复。

## 4. 验收门槛
- 主要站点通过；识别准确率与下载成功率达到预期；设置项生效且持久化。# 测试策略（Testing）

- 单元测试：使用 Vitest，覆盖 `src/utils`、`src/services`、`src/messaging` 的纯函数与协议。
- 组件测试：使用 Vue Test Utils + Vitest，覆盖侧边栏/弹窗/设置页的关键交互。
- 端到端：使用 Playwright，覆盖基础加载、站点识别与按钮交互。
- 覆盖率门槛：语句/分支/函数/行 >= 80%。
- 运行命令：
```powershell
npm run test
```
